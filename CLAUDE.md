## antislop
For UI, copy, and layout work, read `DESIGN.md` for direction, then `antislop.md` (core filter). Only the core is installed; the optional skills (`antislop-ui`, `antislop-copywriting`, `antislop-human`, `antislop-layoutmobile`, `antislop-code`) are not present.
Mode: during. Run the Delivery Gate before delivering any UI work and report PASS/FAIL per item.
To update antislop later: download `antislop.md` again, or run `npx antislop-ai --update`.
